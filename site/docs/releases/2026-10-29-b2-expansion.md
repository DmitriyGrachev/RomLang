## Учебные возможности

- Один основной маршрут A0–B2, входная диагностика без автоматического присвоения CEFR, справочник и очередь повторения.
- Раздельный учёт просмотра, помощи, знакомого задания, самостоятельного ответа и удержания спустя сутки. Точные формы и диакритика проверяются отдельно; открытые объяснения не получают автоматического зачёта.
- 120 основных письменных задач и 120 задач переноса, черновики, версии, ручные рубрики и журнал конкретных ошибок. Самопроверка и внесённая оценка преподавателя различаются.
- Задания для устного ответа и взаимодействия, запись микрофона, локальное скачивание и приватное сохранение в аккаунт с возможностью удаления. Автоматической оценки произношения нет.
- 240 авторских сценариев аудирования, отдельный новый контекст, вопросы и учёт открытой расшифровки. Озвучка использует доступный румынский голос браузера и обозначена как синтетическая. Присутствуют внешние ресурсы с естественной речью и официальный аудиообразец RoExam.
- Три полных авторских пробника B2: обучающий и два резервных. В каждом 20 вопросов аудирования, 20 чтения, 50 грамматики/лексики, две письменные и три устные задачи. Есть оригинальные модели письменных ответов и иллюстрации для сравнения.
- Версионируемый профиль экзамена, пять отдельных компонентов, таймер, неизменяемая копия заданий, отдельные баллы и источники продуктивных оценок. Пройденный вариант не выдаётся за незнакомый.

## Сохранение и совместимость

D1 остаётся основным хранилищем истории. Новые study/exam события добавлены к прежнему журналу без удаления старых типов и без изменения схемы базы. Медиа хранятся отдельно в R2 с ключом аутентифицированного пользователя.

Для вошедшего пользователя временная копия в `sessionStorage` восстанавливает текущую вкладку после перезагрузки при сбое связи. Она привязана к проверенному сервером аккаунту и не заменяет серверное сохранение. Гости работают в памяти открытой вкладки. Закрытие вкладки до подтверждения сервера может удалить временные данные; интерфейс предупреждает об этом.

Смена аккаунта блокирует отправку прежней очереди. Повторная отправка не дублирует события. Повреждённая копия не перезаписывается пустыми данными. Если другой клиент уже завершил часть пробника, конфликтующий локальный ответ сохраняется отдельно для просмотра/экспорта и не меняет завершённый результат. Остальные ответы продолжают синхронизироваться. Импорт обычного экспорта объединяет события; отдельный список конфликтов предназначен для ручного разбора.

## Проверка

Выполнены локальные проверки типов, тесты движка и транспорта, валидаторы контента и производственная сборка. Финальные команды:

```sh
npm test
npx --no-install tsc --noEmit
npm run check:content
npm run check:teaching
npm run check:depth
npm run check:deep
node /root/.codex/plugins/cache/openai-curated-remote/sites/1.1.2/scripts/build-site.mjs
```

28 тестовых файлов охватывают прежние сценарии и новые регрессии: строгую проверку ответов, повторную серверную валидацию аудирования, экспорт/импорт, медиа-лимиты, замороженные пробники, продолжение времени, восстановление после сбоя, разные аккаунты, повреждённую копию и конфликт ответов между клиентами.

Сборка предупреждает о крупном клиентском пакете: около 13,7 МБ до сжатия и 2,45 МБ gzip. Скорость загрузки и отклика на реальном мобильном устройстве пока не измерена.

Независимый технический разбор выявил и помог исправить дефекты повторной проверки аудирования, восстановления очереди, повреждённого кеша и устаревших ответов. После предметного повторного разбора не осталось подтверждённых Critical/Important замечаний в проверенной области. Это не заменяет ещё не выполненную браузерную проверку.

## Границы готовности

Материалы написаны и проверены авторами и дополнительными проходами по ключам и методике. Проверка носителем языка/профессиональным преподавателем для всего нового банка не проводилась. Пробники не проходили внешнюю психометрическую калибровку.

Носительские записи для всего нового курса, живое взаимодействие и реальная преподавательская оценка не могут быть заменены программной отметкой. Эти ограничения явно показаны в приложении. Полная адаптация под фактический экзаменационный центр потребует выбранного пользователем провайдера.

Рабочий профиль сверён с RoExam 2026-10-29. Официальный проходной порог не утверждается; 80/100 и 14/20 по компоненту — предварительные внутренние ориентиры. Даже их выполнение на авторских вариантах не является гарантией сдачи B2.

## Продолжение публикации

1. Восстановить разрешённый доступ к штатному Git-сервису Sites.
2. Получить свежий credential для того же проекта; передать его только скрытому stdin штатного `site-workflow.mjs`.
3. Открыть/сверить удалённую ветку, не перезаписывая возможные новые изменения.
4. Собрать, сохранить и отправить точный коммит; упаковать архив штатным workflow.
5. Создать новую Sites version с тем же SHA и архивом, затем опубликовать с сохранением текущей публичной аудитории.
6. Проверить размещённый интерфейс, вход, сохранение, таймер и запись голоса. Ни один локальный результат в этом документе не означает, что этот шаг уже выполнен.
