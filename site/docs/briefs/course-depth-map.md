# Expansion map: function, language and transfer

The original6modules/24lessons in each level remain the foundation. The following6modules deepen application at that level before moving on. Their four lesson microsteps were supplied to the respective authors; this is the shared cross-level map. Each checkpoint revisits the listed prior constructions in different facts/roles. Passages and prices are fictional. Productive tasks are self-check, not automated CEFR certification.

## Recurrence and skill boundaries
The overview allocates review, new language, targeted exercises, authentic listening, independent speech/writing and reflection inside the chosen60/75/90minutes; these are suggested budgets, not measured study time. Hard topics can span days. Use existing due/error review; after each block perform a checkpoint in changed facts and a second mission variant. Revisit the same skill after a delay.

Objective tasks assess written reading/grammar. End-of-module writing/speech uses a prompt, full model and self-check; it does not receive a fabricated machine score. Natural listening currently uses the linked official resources and must be reported as external. Keep some ILR sample tests unseen for a level boundary. No course-count threshold or XP figure establishes a CEFR level.
