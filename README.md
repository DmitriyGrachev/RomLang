# RomLang — румынский от нуля до B2

Репозиторий содержит два варианта курса с пояснениями на русском:

| Каталог | Назначение |
| --- | --- |
| [`site/`](site/) | Полная подготовленная версия сайта A0–B2 с углублённой теорией, практикой и пробными экзаменами. |
| [`source/`](source/) и файлы запуска в корне | Локальное приложение версии 2.0 для работы на компьютере. Инструкция приведена ниже. |

## Полная версия сайта A0–B2

Каталог `site/` содержит полное дерево исходников подготовленной версии сайта Română Militari из коммита `070315ee069f073daf76a9d015760b9483193665`.

- 120 новых глав A0–B2 и 360 учебных целей.
- 3182 задания: практика, самостоятельный контроль и отложенная проверка.
- 240 сценариев аудирования, письменная практика и устные задания.
- Три пробных экзамена B2 с таймерами и отдельными компонентами.
- Сохранены 192 прежних урока и 76 тем академии.
- Отслеживание освоения, повторение, журнал ошибок и восстановление несохранённых записей после перезагрузки вкладки.

### Среда исполнения

Эта версия использует React/Vinext и серверный Cloudflare Worker. Облачное сохранение прогресса использует D1, загрузка аудиозаписей — R2, а размещённая версия получает авторизацию от платформы Sites. Для запуска требуется соответствующая серверная среда; это не статическая сборка для GitHub Pages.

Требования и инструкции среды исполнения находятся в [`site/README.md`](site/README.md). Проверки курса запускаются из каталога `site/`:

```sh
npm test
npm run check:content
npm run check:teaching
npm run check:depth
npm run check:deep
```

Сборка и публикация выполняются по инструкции Sites в том же каталоге. Команды `npm run setup`, `npm run build` и `npm start` из корня репозитория относятся к локальному приложению в `source/`.

### Проверка и статус

При подготовке версии прошли все 28 файлов тестов, проверка TypeScript, валидаторы учебного содержания и производственная сборка. Полный отчёт, ограничения и результаты проверок: [изменения A0–B2 от 29 октября 2026](site/docs/releases/2026-10-29-b2-expansion.md). План реализации: [complete-b2](site/docs/superpowers/plans/2026-10-29-complete-b2.md).

Публикация исходников в этом репозитории сама по себе не обновляет [размещённый сайт](https://romana-militari.hrachevdmitry.chatgpt.site/).

## Локальное приложение 2.0

Исходники курса Română версии **2.0.0**: уроки, теория, словарь и письменная практика уровней A1–B2 с пояснениями на русском. Курс запускается на компьютере и сохраняет прогресс в своей папке.

### Требования

- Node.js **22.13.0 или новее** и npm.
- Современный браузер: Chrome, Edge, Firefox или Safari.
- Интернет для установки зависимостей. После сборки уроки и сохранение прогресса работают локально. Ссылки на ChatGPT и внешние учебные материалы требуют интернета.

### Подготовка и запуск

Загрузите репозиторий целиком. Откройте терминал в папке `RomLang` и выполните:

```sh
npm run setup
npm run build
npm start
```

Откройте в браузере **http://127.0.0.1:47833/**. Сервер доступен только на этом компьютере. Для остановки нажмите `Ctrl+C` в терминале.

На Windows после подготовки и сборки можно открывать **Start.cmd** двойным щелчком. Он запускает сервер в фоне и открывает курс отдельным окном в Chrome или Edge; при отсутствии этих браузеров — в браузере по умолчанию. Повторный запуск использует уже работающий сервер этой же копии. После закрытия окна сервер продолжает работать до перезагрузки компьютера.

Windows-запуск использует `runtime/node.exe`, если этот файл добавлен вручную, иначе ищет установленный Node.js в `PATH`. Готовый Node.js в репозиторий не включён. Ошибки фонового запуска записываются в `runtime/server-error.log`.

### Команды

| Команда | Действие |
| --- | --- |
| `npm run setup` | Устанавливает зависимости из `source/package-lock.json` командой `npm --prefix source ci`. |
| `npm run build` | Собирает интерфейс из `source` в папку `www`. |
| `npm start` | Запускает локальный сервер: `node --experimental-strip-types server.mjs`. |
| `npm test` | Проверяет локальный сервер и учебную логику встроенными тестами Node.js. |

После изменения исходников интерфейса повторите `npm run build`, затем обновите страницу курса. Перед переносом папки или заменой исходников остановите сервер; при фоновом запуске Windows проще перезагрузить компьютер.

### Прогресс и резервная копия

При первом обращении к курсу сервер создаёт `data/learning-events.json`. Прогресс сохраняется автоматически, предыдущая сохранённая версия остаётся рядом как резервная копия. Перед закрытием дождитесь сообщения «Прогресс сохранён на компьютере».

Для переноса используйте экспорт и импорт на странице прогресса. Импорт объединяет записи. Также можно скопировать папку `data`, предварительно остановив сервер. Не редактируйте файлы прогресса во время работы курса.

Личная история обучения, резервные копии и облачные учётные данные в этот репозиторий не включены. Локальная копия не синхронизирует прогресс с сайтом в интернете.

### Файлы проекта

- `source/` — интерфейс, учебные материалы, проверки и зависимости сборки.
- `source/docs/romanian-curriculum.json` — программа курса, необходимая для сборки и работы сервера.
- `server.mjs` — локальный сервер и сохранение прогресса.
- `Start.cmd`, `launch.ps1` — запуск на Windows.
- `www/` — результат сборки; создаётся командой `npm run build` и исключён из Git.
- `data/`, `runtime/`, `source/node_modules/` — локальные данные и служебные файлы; исключены из Git.

Курс предназначен для самостоятельной практики. Он не выдаёт сертификат и не заменяет независимую оценку уровня языка.
